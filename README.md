# Arunkumar P — Portfolio

Personal portfolio site for **Arunkumar P**, a full-stack / backend developer — built with React 19, Vite, TypeScript, and Framer Motion.

**Live:** [workbridge.hanbee.in](https://workbridge.hanbee.in) &nbsp;·&nbsp; **GitHub:** [Arunkumar3624](https://github.com/Arunkumar3624)

## Highlights

- Dual light/dark theme with an elegant "Cyprus + Sand" light palette and a pink/violet/cyan signature gradient
- Custom cursor with a masked image-reveal effect on the hero and about photos
- Kinetic per-word text reveals on section titles
- Featured project case studies with honest, specific "how I solved it" technical write-ups
- A site-styled résumé page (`/resume.html`) with print-to-PDF support

## Stack

React 19 · TypeScript · Vite · Framer Motion · Lenis (smooth scroll) · CSS Modules

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Note on images

The personal photos used across the site live in `src/assets/images/` and are required for the build to succeed — don't remove them without swapping in replacements.
